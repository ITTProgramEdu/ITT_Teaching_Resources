### 经验分享：

其实也说不上有很多有用的经验，主要把自己怎么做机器人的过程叙述一遍吧！

1.首先最好去参加中控杯的三次培训，了解一下基本的规则和机器人知识。

2.翻阅历届的开源资料，尤其是那些获得了校赛一等奖的队伍，他们的很多方案都值得我们学习，多看看他们的经验分享，因为我们没有时间去踩一些简单的坑。我记得一年前我在一个队伍的经验分享里看到一句话，在这里分享给大家：“不要从轮子造起，要站在巨人的肩膀上”。

3.接下来就是买材料自己搭建机器人了。在买材料的时候首先最好把一些常用的螺丝、杜邦线等等消耗品的各种品种都买全，以免后来需要用的时候还要等快递。其次，买电机电池这种有很多品种的材料最好就是预估一下需要的参数，尽量买大一点留足余量，以免后面迭代浪费钱和时间。还有像电烙铁、钻孔机这种都可以去E志者借，不需要自己购买。最后做一切事情之前一定要有一个计划，做好打算。

4.我们的底板和顶板迭代了3次，电机迭代了2次，轮子迭代了2次......在这个过程中，不合适是必须的，此时就是要找到原因不断改进自己的机器人。

5.一定要仔仔细细地多读几遍规则，我们因为没理解清楚规则导致很多的结构在比赛的时候无法使用。

6.我们三个都不是控制学院的，对机器人方面没有基础知识，但是三个人齐心协力，还是干出了一番成就，这里要感谢很多给我们提供建议的学长学姐。文件夹里的方案有很多并不是最终方案，因为时间匆忙，没有时间更新了，所以如果有需要我帮助的地方，可以随便联系我！
